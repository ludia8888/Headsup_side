# 지민 UI/UX 개선 방향

**현재 적용 버전은 v2입니다.** 현재 공개된 Character.AI·Nomi·러비더비 화면을 검토한 뒤 전체 캐릭터 장면, 보라빛 어두운 바탕, 고정 전화 버튼으로 다시 구성했습니다. 최신 디자인·검증·참고 링크는 [v2 제작 기록](UI_REDESIGN_V2.md), 캐릭터 생성 프롬프트는 [v2 이미지 기록](CHARACTER_SCENE_V2.md)에 있습니다. 아래 내용은 이전 v1 작업 기록입니다.

2026-09-29. 성인 한국어 사용자를 위한 친밀한 AI 전화 경험. 홈은 관계와 목소리, 설정은 연락의 경계, ‘우리’는 사용자가 확인한 기억에 집중한다.

## 디자인 토큰

- 바탕 Cloud `#F6F8FC`, 카드 White `#FFFFFF`, 본문 Ink `#202C45`, 보조 Slate `#65718A`, 강조 Blue `#375BD2`, 연한 Periwinkle `#E9EEFF`.
- 글꼴: iOS 기본 한국어 서체를 사용하고, 제목은 28~34pt의 또렷한 굵기, 본문 16~17pt, 보조 13~14pt. Dynamic Type에 따라 확장한다. 영문 장식 글꼴을 한국어에 억지로 적용하지 않는다.
- 간격: 4/8/12/16/20/24/32. 화면 좌우 24pt, 주 버튼 최소 높이 56pt, 보조 액션 최소 터치 영역 44pt.
- 모서리: 큰 인물 영역 32pt, 기능 묶음 20pt, 입력 14pt. 카드마다 같은 그림자나 과도한 장식을 반복하지 않는다.

## 화면 구조

```text
AI                    우리                  설정
오늘 인사 / 상태       이름 / 함께한 날짜     프로필 요약
캐릭터 인물            기억에 대한 약속       연락과 휴식
지민의 짧은 메시지     확인한 기억 목록       앱별 한도
최근 실제 통화         기억 추가              성격과 목소리
통화 버튼              수정 / 삭제            연결과 권한
```

온보딩은 단계 진행과 하단 고정 버튼으로 구성한다. 한 화면에서 한 가지 선택을 중심에 두고, 권한과 자동 연락의 실제 상태를 짧게 설명한다. 통화 화면은 수신, 연결 중, 대화, 조용한 동행을 각각 다른 상태로 표시한다.

## 사전 검토와 수정

기존의 크림색·세리프·큰 분홍 원 얼굴은 템플릿 느낌이 강하고 성인용 음성 관계보다 장난감처럼 보였다. 밝은 회색 바탕과 깊은 블루, 하나의 고유 캐릭터 일러스트로 바꾸고 주변 장식은 줄인다. 숫자 대시보드와 집중 점수는 도입하지 않는다. 초록색 온라인 표시를 연결 증거 없이 보여주지 않는다. 통화 실패나 빈 기억 목록에는 다음 행동을 안내한다.

## 검증 기준

- 작은 iPhone에서도 핵심 버튼이 잘리지 않고, 큰 글자에서도 내용을 스크롤할 수 있다.
- VoiceOver에 버튼 목적과 선택 상태가 전달된다. 색상만으로 선택·오류를 구별하지 않는다.
- 기억을 저장하기 위한 확인과 삭제 확인이 분명하다.
- 서버 연결 저장, 실제 음성 준비, 자동 전화 승인 상태를 섞지 않는다.
- 시뮬레이터의 실제 렌더와 동작을 캡처하고, 실기기 음성·Apple 승인은 별도 판정한다.

## 적용 결과와 실제 검토

- SwiftUI 화면과 공통 버튼·입력·상태 표시를 교체했다. 홈의 통화 버튼은 내용 스크롤과 분리하고 하단 탭은 실제 레이아웃 공간을 갖도록 수정했다. 초기 검토에서 발견한 버튼 겹침을 해결했다.
- 이름·호칭·성격·목소리 편집은 임시 값으로 시작하고 ‘완료’에서 저장한다. 취소하면 변경하지 않는다. 빈 이름/호칭은 안내하고 저장을 막는다.
- ‘우리’의 빈 목록, 기억 작성, 글자 수, 명확한 저장 동의와 취소를 실제로 눌러 확인했다. 빈 내용의 저장이 비활성화되고, 임시 문장을 입력한 뒤 취소했을 때 빈 목록이 유지됐다.
- iPhone 17 Pro에서 홈·우리·기억 작성·설정 상단의 실제 표시를 확인했다. 접근성 글자 크기 accessibility-large에서도 홈의 통화 버튼과 하단 탭이 표시된다. 최종적으로 원래 글자 크기 large로 복구했다.
- 별도 iPhone SE 3세대에서 첫 설정 화면과 하단 ‘다음’ 버튼의 표시를 확인했다. 성격 선택 전체와 이후 여섯 단계의 작은 화면 조작 완료는 확인하지 못했다. 검토 중 컴퓨터 조작 도구가 시뮬레이터 창에 연결하지 못해 추가 UI 조작을 중단했다. 해당 시험 기기는 종료했고 기존 기기의 데이터는 지우지 않았다.
- VoiceOver용 이름·선택 상태와 동작 줄이기를 코드에 반영했다. 실제 VoiceOver 읽기·전체 화면의 최대 글자 크기·실기기 이어폰/수신 UI는 별도 검증이 필요하다.
- 최종 앱+확장 기능 빌드, Swift 17개/서버 18개 검사 통과. 실제 OpenAI 음성 연결과 Apple 자동 전화 승인은 통과로 기록하지 않는다.

후속 제품 변경: 홈 메시지, 성격 소개·음성 예시, 연락의 약속, 통화 첫 발화를 ‘매번 다른 재미있는 이야기’에 맞췄다. direct의 저장 값은 유지하면서 표시 이름을 ‘직설적이고 장난스러운’으로 바꿨다. 할 일 시작이나 동행을 모든 통화의 기본 결론으로 유도하지 않는다.
