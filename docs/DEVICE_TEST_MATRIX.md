# 실기기·TestFlight 검증표

판정 값: **passed / failed / blocked / notProven**. 실제 증거가 없으면 notProven으로 둡니다. 수동 실기기 통화는 확인했으며, 앱 사용 감지·자동 수신·배포 경로의 승인 조건은 여전히 **blocked(승인 증거 미확보)** 입니다.

시험 기록에는 앱/서버 버전, iPhone 모델·iOS 버전·시간대, 앱/확장 기능 서명, 마이크/Screen Time 권한, APNs 환경, 연결망, 관찰 시각을 적습니다. 앱 토큰이나 원본 사용 보고서를 수집하지 않습니다.

## 1. 감지 — 승인 전에는 기기 안에서만

| 시험 | 방법 | 기대 결과 | 판정 |
|---|---|---|---|
| 앱별 독립 집계 | 앱 A 15분, B 30분을 지정해 각각 사용 | A/B 이벤트가 독립적으로 도착 | notProven |
| 중간 휴식 | A를 8분 사용 후 중단, 다시 8분 사용 | 연속 16분이 아니어도 하루 15분 이벤트 발생 | notProven |
| 날짜 변경 | 자정 전후 사용, 필요하면 시차 변경도 별도 시험 | 현지 날짜가 바뀔 때만 당일 기록 초기화 | notProven |
| 한도 낮춤·높임 | 오늘 이미 사용한 뒤 한도 변경 | 기존 사용 포함, 이미 시도한 통화 횟수 보존 | notProven |
| 제거·같은 날 재선택 | 같은 앱을 제거했다가 다시 선택 | 같은 날 기존 ID/시도 기록 유지 | notProven |
| 권한 철회 | 설정에서 Screen Time 권한을 철회 | 자동 신호 억제, 다시 앱 열면 모니터링 정지 | notProven |
| 관련 웹사이트 | 선택 앱의 연결된 사이트를 Safari에서 사용 | 암묵적으로 포함되는지 기록하고 기대와 대조 | notProven |
| 승인 전 전송 없음 | 네트워크 관찰과 로컬 로그 비교 | 감지 파일만 갱신, 서버 요청·전송 파일 없음 | notProven |
| 새 일정·재시작 | 당일 앱/확장 기능 재시작 | 같은 날짜의 횟수가 초기화되지 않음 | notProven |

## 2. 수신 — 승인·배포 권한 확보 후 통합

| 시험 | 기대 결과 | 판정 |
|---|---|---|
| 시뮬레이터 수동 시험 | 홈 ‘대화하기’ → 앱 안 수신 화면 → ‘받기’ → GPT-Live 세션 생성·WebRTC `session.started` 기록. 실제 왕복 소리는 별도 확인 | 신호 연결 passed, 실제 소리 notProven |
| 실기기 수동 전경 시험 | `JiminManualDemo` 설치·실행 후 사용자 요청 → 수신 화면 → 실제 왕복 음성. APNs 없이 시험 | 설치·실행·사용자 확인 음성 passed. 수정 후 받기 전 iPhone 상단 시스템 전화 알림만 표시되고, 수락 후 앱 통화 화면과 음성이 이어짐을 사용자 확인. 잠금 화면/백그라운드/강제 종료 수신 notProven |
| 일반 백그라운드 자동 수신 | 임계치 → 최소 신호 → APNs → CallKit을 순서별로 기록 | blocked |
| 앱 강제 종료 상태 | 일반 백그라운드와 별도 측정. 도착하지 않으면 실패로 기록 | blocked |
| 두 앱이 거의 동시에 한도 초과 | 한 통화만 진행. 추가 이벤트를 나중에 몰아서 전화하지 않음 | blocked |
| 동일 요청 중복 | 같은 UUID로 시스템 전화가 추가 생성되지 않음 | blocked |
| 첫 전화 거절·부재중 | 결과 이후 같은 앱의 추가 사용 감지 등록 | blocked |
| 20분 동안 다른 일만 함 | 시간만 흘러서는 재전화 없음 | blocked |
| 같은 앱 추가 20분 사용 | 한 번만 재전화. 추가 사용 기준 등록 시각도 기록 | blocked |
| 첫 전화 받음 | 같은 앱은 그날 추가 자동 전화 없음 | blocked |
| 재전화 중 새 임계치 | 기존 통화에 추가하거나 통화 후 대기열로 남기지 않음 | blocked |
| 요청 지연·오프라인 | 60초 지난 이벤트 거부, 만료된 수신 즉시 종료 | blocked |
| 오늘 쉬기·먼저 전화 끄기 | 새 요청 억제. 이미 도착한 VoIP 요청도 보고 후 종료 | blocked |
| 방해금지·차단·배너 설정 | OS 결과를 그대로 기록. 항상 전체 화면이라고 주장하지 않음 | notProven |
| 재시작 중단 통화 | 이전 음성 연결 실패로 정리, 당일 이미 받은 앱 기록 보존 | notProven |

| 시험 | 기대 결과 | 판정 |

| 한국어 왕복 음성 | 사용자의 말과 AI 응답이 실제로 서로 들림 | notProven |
| 첫마디와 반응 | 받자마자 질문이 들리고 잔소리나 안내가 앞서지 않음. 첫 발화·첫 응답까지 걸린 시간과 실제 발화 내용을 분리해 확인 | notProven |
| GPT-Live 세션·작업 위임 | `session.started`, 즉흥 대화, 작업 모델 도구 호출과 결과 복귀를 각각 확인 | notProven |
| 페르소나 3개 | 같은 상황에 세 말투가 구분되고 강압/조롱 없음 | notProven |
| 이름·호칭·목소리 변경 | 통화 중 그대로 유지, 다음 통화에 반영 | notProven |
| 말 끼어들기 | AI 발화 중 말하면 중단하고 사용자에게 응답 | notProven |

| 20분 동행과 긴 침묵 | 사용자 동의 후 유지. 혼자 계속 말을 걸지 않음 | notProven |
| 끝 인사·사용자 끊기 | 20분 종료 인사, PC/마이크/서버 통화 정리 | notProven |

| 네트워크 단절·복구 | 실패를 숨기지 않고 정리. 유령 통화·임의 재전화 없음 | notProven |
| API 키 없음·모델 접근 실패 | 연결 실패로 표시. 가짜 AI 대화 없음 | 자동 서버 검사는 passed, 실기기는 notProven |

## 4. 기억과 동의

| 시험 | 기대 결과 | 판정 |
|---|---|---|
| 제안만 하고 동의 안 함 | 확정 목록·서버 설정·다음 통화에 없음 | notProven |
| ‘아니’ 또는 애매한 대답 | 저장하지 않음 | notProven |
| 이전 질문의 ‘응’ 재사용 | 저장하지 않음 | 자동 검사 passed, 실기기 notProven |
| 늦게 도착한 음성 조각·부정 정정 | 앞의 “응” 다음 “아니”가 오면 저장하지 않음 | 자동 검사 passed, 실기기 notProven |
| 동행 질문에 대한 ‘응’ | 기억 저장 동의로 사용하지 않음 | 자동 검사 passed, 실기기 notProven |
| 확인 질문 뒤 “기억해 줘/저장해 줘” | 해당 후보만 저장. 서버로 확인된 기억만 동기화 | notProven |
| 확인 버튼 | 해당 텍스트를 직접 확인 후 저장 | notProven |
| 수정·삭제 | 다음 통화에서 새 확정 목록 사용 | 자동 서버 검사 passed, 실기기 notProven |
| 오늘 연락 중단·부정문 | 명확한 중단 요청만 일시정지. ‘멈추지 마’는 중단 아님 | 자동 검사 passed, 실기기 notProven |

## 5. 성인 사용자 실험

각 참여자에게 감지/관찰과 전화에 대한 동의를 받고 시험합니다. 강제 앱 차단이 아니므로 통화를 받았다는 사실만으로 앱을 멈췄다고 기록하지 않습니다.

| 항목 | 관측 방법 | 현재 |
|---|---|---|
| 전화를 받는가 | 실제 수신/거절/부재중, 실제 음성 연결을 따로 집계 | notProven |
| 첫마디에 반응하고 싶은가 | 통화 후 선택식 자기보고와, 동의한 실기기 시험의 첫 사용자 응답 여부·지연을 함께 봄. 둘 다 흥미의 직접 증거로 단정하지 않음 | notProven |
| 이후 그 앱 사용을 멈추는가 | 통화 후 설문, 동의한 관찰. 초기에는 자기보고임을 표시 | notProven |
| 다음날도 전화를 원하는가 | 통화 후 설문 + 다음날 실제 재참여 여부 | notProven |

분모를 함께 기록합니다: 요청 수, 시스템 수신 표시 수, 실제 음성 연결 수, 응답한 설문 수. 승인 전 수동 시험의 수신율을 자동 전화 수신율로 섞지 않습니다.
